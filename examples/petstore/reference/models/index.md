# Models

Reusable schemas are documented once and linked from every operation that uses
them. An OpenAPI `$ref`, such as `#/components/schemas/Pet`, always links to the
corresponding model page instead of expanding an inline schema.

| Model | Description |
| --- | --- |
| [API response](api-response.md) | Result metadata returned by file uploads. |
| [Category](category.md) | A pet category. |
| [Order](order.md) | A store order for a pet. |
| [Pet](pet.md) | A pet managed by the store. |
| [Tag](tag.md) | A searchable pet label. |
| [User](user.md) | A Petstore user account. |
