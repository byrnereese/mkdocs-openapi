# Category

A category used to group pets.

## Properties

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | integer · int64 | No | Unique category identifier. |
| `name` | string | No | Category name. |

## Example

```json
{
  "id": 1,
  "name": "Dogs"
}
```
