# Tag

A searchable label attached to a pet.

## Properties

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | integer · int64 | No | Unique tag identifier. |
| `name` | string | No | Tag name. |

## Example

```json
{
  "id": 7,
  "name": "friendly"
}
```
