# Log out

`GET`{ .http-method .get } `/user/logout`{ .operation-path }

End the current user session.

**Operation ID:** `logoutUser`  
**Authorization:** None

## Responses

| Status | Description |
| --- | --- |
| `200` | Successful operation. |
| `default` | Unexpected error. |
