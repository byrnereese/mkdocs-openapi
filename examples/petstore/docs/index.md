# Swagger Petstore API

Use the Petstore API to manage pets, orders, and users. This site demonstrates
the API-reference format produced by `mkdocs-openapi`.

!!! info "Reference implementation"

    These pages are a design fixture, not a replacement for the source
    specification. They are rendered from Markdown with MkDocs Material and use
    only a small amount of API-specific CSS.

## Base URL

```text
https://petstore3.swagger.io/api/v3
```

## Explore the API

| Resource | Purpose |
| --- | --- |
| [Pet](api-reference/pet/index.md) | Create, find, update, and remove pets. |
| [Store](api-reference/store/index.md) | Inspect inventory and manage orders. |
| [User](api-reference/user/index.md) | Create users and manage user sessions. |
